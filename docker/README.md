# docker/

Jazzy + Gazebo Harmonic image for development, simulation, and CI (amd64).

| File | Purpose |
|---|---|
| `Dockerfile` | `base`: `osrf/ros:jazzy-desktop-full` + rmw_zenoh, ros2_control, Nav2, slam_toolbox, robot_localization, twist_mux, joy, teleop, rplidar_ros, ros_gz, gz_ros2_control, DriveLink apt (key pinned by fingerprint) + `ros-jazzy-drivelink-bringup` → `dev`: tools, user `riggu` with the host UID/GID, passwordless sudo |
| `compose.yaml` | Service `dev`, image `riggu_ws:jazzy-dev`. Static settings only: workspace at `/ws`, host network, host IPC |
| `compose.override.yaml` | Generated by `scripts/docker_run.sh` (git-ignored): display, GPU, `RIGGU_*` env |

```bash
scripts/docker_run.sh                    # interactive shell; builds the image on first use
scripts/docker_run.sh --build            # rebuild
scripts/docker_run.sh bash -lc 'colcon build --symlink-install'
```

`docker_run.sh` detection (override with `--display` / `--gpu` or `RIGGU_DISPLAY` / `RIGGU_GPU`):

| | Order |
|---|---|
| Display | `wslg` (`/mnt/wslg`) → `wayland` → `x11` → `none` |
| GPU | `wsl` (`/dev/dxg`, Mesa d3d12 on the Windows GPU) → `nvidia` (`--gpus all`) → `dri` (`/dev/dri`) → `software` (`LIBGL_ALWAYS_SOFTWARE=1`) |

Interactive shells source `scripts/env.sh ${RIGGU_PROFILE:-sim}` (Jazzy, workspace, local zenoh router). The ROS entrypoint sources Jazzy for non-interactive commands.

`.devcontainer/` (`initializeCommand` writes the override) and CI (`.github/workflows/ci.yml`, GHA layer cache) use the same image.

**Host requirements:** Docker Engine plus nvidia-container-toolkit (for an NVIDIA GPU). On WSL2, install the engine inside the distro, not Docker Desktop (`scripts/setup_host_tools.sh`).
